# Guías

### Propósito de este documento

- **Objetivos:** Indexar las guías transversales en español sin mover los
  runbooks ni las rutas históricas `docs/guias/`.
- **Estructura:** Tabla de alias `guides/` → ficheros vigentes en `guias/`.
- **Contenido a integrar según contexto:** No dupliques el cuerpo de las
  guías. `SUPPORT.md` y los runbooks vivos siguen enlazando `docs/guias/`.
